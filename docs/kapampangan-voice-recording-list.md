# Kapampangan voice recording list

Kapampangan has no text-to-speech voice, so a lesson item without a recording shows "Audio coming soon". `assets/audio/kapampangan` has three files (`Abak.m4a`, `Bengi.m4a`, `Mayap.m4a`), but the app doesn't use them yet, so everything below still counts as needing a recording. Those three words are in the list (Mayap in Lesson 1, Abak and Bengi in Lesson 4), so the files may be reusable.

Taken from the app's lesson data (`data/lessons/kapampangan-lesson*.ts` and `kapampanganPracticeLevels` in `data/practiceData.ts`). Stories are not included.

Much of this text is a working translation that a native speaker hasn't checked. Have a native speaker confirm it before recording, so nothing has to be recorded twice.

- **Levels:** Easy is Lessons 1–10, Intermediate is 11–20, Hard is 21–30.
- **Check first:** the source document marks this phrase "(?)", or the data marks it "TODO: check". Confirm these before anything else.
- **Already recorded in:** the same text appears in an earlier lesson, so that recording can be reused.
- **Two forms, like "Nukarin / Nokarin":** 20 first-time word rows list two forms, and the pronunciation usually covers only the first. Decide which form to record, or whether to record both, because each extra form adds a clip.
- **Pronunciation is copied from the lesson data.** It isn't always right: "Paalam" is listed as "a-di-yos", which looks like the respelling of a different word. Lesson 6 food names use a different respelling style (for example "ah-DOH-boh"), and "Kalamansi juice" and "Buko juice" cover only the first word.
- **—** means the lesson data has no value for that column.
